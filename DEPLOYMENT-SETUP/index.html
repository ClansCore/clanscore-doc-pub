    🔧 Dokumentations-Deployment Setup¶

    Kurzanleitung zum Einrichten des automatischen Deployments der Dokumentation vom privaten ins öffentliche Repository.

    ⚡ Schnellstart (Repos in derselben Organisation)¶

    Wichtig: Der GITHUB_TOKEN hat nur Zugriff auf das aktuelle Repository. Für Cross-Repository-Zugriff benötigen Sie einen Personal Access Token.

    Personal Access Token erstellen (Erforderlich)¶

    1. Personal Access Token erstellen:
    2. Gehen Sie zu: GitHub Settings → Developer settings → Personal access tokens → Tokens (classic)
    3. Klicken Sie auf Generate new token (classic)
    4. Name: clanscore-doc-deploy
    5. Scopes: ✅ repo (vollständiger Zugriff)
    6. Klicken Sie auf Generate token

    7. Token kopieren (wird nur einmal angezeigt!)

    8. Secret hinzufügen:

    9. Gehen Sie zu: ClansCore/clanscore → Settings → Secrets and variables → Actions
    10. Klicken Sie auf New repository secret
    11. Name: PUBLIC_REPO_DEPLOY_TOKEN
    12. Value: Den kopierten Token einfügen
    13. Klicken Sie auf Add secret

    3. GitHub Pages aktivieren¶

    1. Gehen Sie zu: ClansCore/clanscore-doc-pub → Settings → Pages
    2. Source: Deploy from a branch
    3. Branch: main (oder master)
    4. Folder: / (root)
    5. Klicken Sie auf Save

    Fertig! ✅¶

    Nach dem nächsten Push zu docs/** oder mkdocs.yml wird die Dokumentation automatisch deployed.

    Die Dokumentation ist dann verfügbar unter: https://clanscore.github.io/clanscore-doc-pub/

    Manuell testen¶

    Sie können den Workflow auch manuell auslösen:

    1. Gehen Sie zu: ClansCore/clanscore → Actions
    2. Wählen Sie Deploy Documentation
    3. Klicken Sie auf Run workflow

    Troubleshooting¶

    "Permission denied" beim Push¶

    • Der GITHUB_TOKEN funktioniert nicht für Cross-Repository-Zugriff: Sie müssen einen Personal Access Token verwenden
    • Prüfen Sie: Ob der Token die repo Scope hat und Zugriff auf die Organisation hat
    • Prüfen Sie: Ob der Secret PUBLIC_REPO_DEPLOY_TOKEN korrekt gesetzt ist

    "Repository not found"¶

    • Prüfen Sie, ob alle Repos in derselben Organisation sind
    • Prüfen Sie, ob der verwendete Token/Benutzer Zugriff auf das öffentliche Repository hat

    Weitere Informationen¶

    Siehe DEPLOYMENT.md für detaillierte Informationen und Troubleshooting.
