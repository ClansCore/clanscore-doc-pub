    !!! 📊 Dashboard - Benutzerhandbuch¶

    Vollständiges Handbuch für das ClansCore Dashboard.

    Was ist das Dashboard?¶

    Das ClansCore Dashboard ist eine moderne Web-Anwendung für die Verwaltung des Vereins. Es bietet Administratoren und Vorstandsmitgliedern eine intuitive Oberfläche für alle Verwaltungsaufgaben.

    Technologie¶

    • Framework: Angular 18
    • Sprache: TypeScript
    • Styling: SCSS
    • Build: Angular CLI
    • Deployment: Nginx (Production)

    Hauptfunktionen¶

    • Benutzerverwaltung

      • Mitglieder-Verwaltung
      • Bewerbungen bearbeiten
      • Rollen zuweisen
      • Punkte verwalten

    • Aufgaben-Management

      • Aufgaben erstellen und verwalten
      • Teilnehmer zuweisen
      • Aufgaben als erledigt markieren
      • Punkte vergeben

    • Event-Verwaltung

      • Events anzeigen und bearbeiten
      • Google Calendar Integration
      • Teilnehmer-Verwaltung

    • Gamification

      • Ranglisten verwalten
      • Belohnungen erstellen
      • Belohnungs-Anfragen bearbeiten
      • Punkte-Historie anzeigen

    • Rollen-Management

      • Rollen erstellen und bearbeiten
      • Rollen mit Discord synchronisieren
      • Berechtigungen verwalten

    Zielgruppe¶

    • Vorstandsmitglieder: Hauptnutzer für Verwaltungsaufgaben
    • Administratoren: System-Verwaltung und Konfiguration

    Anmeldung¶

    Erste Anmeldung¶

    1. Öffnen Sie das Dashboard
    2. Klicken Sie auf "Registrieren"

    3. Geben Sie Ihre Daten ein:

      • Benutzername
      • E-Mail
      • Passwort

    4. Klicken Sie auf "Registrieren"

    Einloggen¶

    1. Geben Sie Ihre Anmeldedaten ein
    2. Klicken Sie auf "Anmelden"
    3. Sie werden zum Dashboard weitergeleitet

    Hauptfunktionen¶

    Benutzerverwaltung¶

    Übersicht:

    • Liste aller registrierten Mitglieder
    • Filter nach Rollen
    • Suche nach Namen oder Discord-ID

    Aktionen:

    • Benutzer anzeigen: Klicken Sie auf einen Benutzer für Details
    • Rollen zuweisen: Benutzer auswählen → Rollen hinzufügen/entfernen
    • Punkte verwalten: Punkte hinzufügen oder entfernen
    • Bewerbungen bearbeiten: Bewerbungen akzeptieren oder ablehnen
    • Benutzer löschen: Benutzer aus dem System entfernen

    Bewerbungen:

    • Neue Bewerbungen werden im Dashboard angezeigt
    • Akzeptieren: Benutzer erhält "Mitglied"-Rolle
    • Ablehnen: Bewerbung wird abgelehnt, Benutzer wird benachrichtigt

    Aufgaben-Management¶

    Aufgaben erstellen:

    1. Navigieren Sie zu "Aufgaben"
    2. Klicken Sie auf "Neue Aufgabe"
    3. Füllen Sie aus:
    4. Titel
    5. Beschreibung
    6. Aufgabentyp
    7. Punkte-Belohnung
    8. Fälligkeitsdatum
    9. Klicken Sie auf "Erstellen"

    Aufgaben verwalten:

    • Offene Aufgaben: Alle verfügbaren Aufgaben
    • Erledigte Aufgaben: Abgeschlossene Aufgaben
    • Abgelaufene Aufgaben: Überschrittene Fälligkeitsdaten

    Aufgaben bearbeiten:

    • Klicken Sie auf eine Aufgabe für Details
    • Teilnehmer verwalten
    • Aufgabe als erledigt markieren
    • Punkte vergeben

    Event-Verwaltung¶

    Events anzeigen:

    • Übersicht aller Events
    • Anstehende Events
    • Event-Details

    Events verwalten:

    • Event-Details bearbeiten
    • Teilnehmer verwalten
    • Events mit Google Calendar synchronisieren

    Ranglisten¶

    Ranglisten erstellen:

    1. Navigieren Sie zu "Ranglisten"
    2. Klicken Sie auf "Neue Rangliste"
    3. Geben Sie einen Namen ein (z.B. "Jahr 2025")
    4. Klicken Sie auf "Erstellen"

    Ranglisten anzeigen:

    • Top-Mitglieder nach Punkten
    • Filter nach Zeitraum
    • Export-Funktion

    Belohnungen¶

    Belohnungen erstellen:

    1. Navigieren Sie zu "Belohnungen"
    2. Klicken Sie auf "Neue Belohnung"
    3. Füllen Sie aus:
    4. Name
    5. Beschreibung
    6. Benötigte Punkte
    7. Verfügbare Menge
    8. Klicken Sie auf "Erstellen"

    Belohnungs-Anfragen:

    • Mitglieder können Belohnungen einfordern
    • Vorstand kann Anfragen akzeptieren oder ablehnen
    • Punkte werden bei Akzeptierung abgezogen

    Rollen-Management¶

    Rollen verwalten:

    • Rollen erstellen
    • Rollen bearbeiten (Name, Farbe, Berechtigungen)
    • Rollen löschen
    • Rollen mit Discord synchronisieren

    Rollen zuweisen:

    • Benutzer auswählen
    • Rollen hinzufügen oder entfernen
    • Änderungen werden automatisch mit Discord synchronisiert

    Navigation¶

    Hauptmenü¶

    • Dashboard: Übersicht und Statistiken
    • Benutzer: Benutzerverwaltung
    • Aufgaben: Aufgaben-Management
    • Events: Event-Verwaltung
    • Ranglisten: Ranglisten-Verwaltung
    • Belohnungen: Belohnungen-Verwaltung
    • Rollen: Rollen-Management
    • Einstellungen: System-Einstellungen

    Benutzer-Menü¶

    • Profil: Eigene Profil-Daten
    • Abmelden: Ausloggen

    Berechtigungen¶

    Rollen¶

    Rolle Berechtigungen
    Mitglied Eigene Daten anzeigen
    Vorstand Alle Verwaltungs-Funktionen
    Admin Vollzugriff + System-Einstellungen

    Funktionen nach Rolle¶

    Mitglied:

    • Eigene Punkte anzeigen
    • Eigene Aufgaben anzeigen
    • Eigene Transaktionen anzeigen

    Vorstand:

    • Alle Benutzer-Funktionen
    • Benutzer verwalten
    • Aufgaben erstellen/bearbeiten
    • Events verwalten
    • Belohnungen verwalten
    • Ranglisten verwalten

    Admin:

    • Alle Vorstand-Funktionen
    • Rollen verwalten
    • System-Einstellungen
    • API-Konfiguration

    Tastenkürzel¶

    • Strg + K: Schnellsuche
    • Strg + S: Speichern (in Formularen)
    • Esc: Dialog schliessen

    Best Practices¶

    Benutzerverwaltung¶

    1. Regelmässige Synchronisation:

      • Synchronisieren Sie regelmässig mit Discord
      • Prüfen Sie neue Bewerbungen täglich

    2. Rollen zuweisen:

      • Verwenden Sie konsistente Rollen-Namen
      • Dokumentieren Sie Rollen-Berechtigungen

    Aufgaben-Management¶

    1. Klare Beschreibungen:

      • Geben Sie detaillierte Aufgaben-Beschreibungen
      • Setzen Sie realistische Fälligkeitsdaten

    2. Punkte vergeben:

      • Verwenden Sie konsistente Punkte-Werte
      • Dokumentieren Sie Punkte-Verteilung

    Event-Verwaltung¶

    1. Kalender-Synchronisation:

      • Synchronisieren Sie regelmässig mit Google Calendar
      • Prüfen Sie Event-Details vor Veröffentlichung

    Troubleshooting¶

    • "Nicht angemeldet"

      • Prüfen Sie Ihre Anmeldedaten
      • Prüfen Sie die API-Verbindung
      • Prüfen Sie die CORS-Konfiguration

    • "Fehler beim Laden"

      • Prüfen Sie die API-Verbindung
      • Prüfen Sie die Browser-Konsole für Fehler
      • Prüfen Sie die Logs: docker-compose logs clanscore-api

    • "Änderungen werden nicht gespeichert"

      • Prüfen Sie Ihre Berechtigungen
      • Prüfen Sie die API-Verbindung
      • Prüfen Sie die Browser-Konsole
