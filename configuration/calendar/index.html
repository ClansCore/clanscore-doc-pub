    📅 Kalender-Integration¶

    Integration mit Google Calendar für Event-Synchronisation.

    Übersicht¶

    Das Clanscore-System synchronisiert Events zwischen Google Calendar und Discord. Events aus dem Google Calendar werden automatisch im Discord-Server angezeigt und können von Mitgliedern verwaltet werden.

    Features¶

    • Bidirektionale Synchronisation: Google Calendar ↔ Discord
    • Automatische Event-Erinnerungen in Discord
    • Teilnahme-Verwaltung über Discord
    • OAuth 2.0 Authentifizierung für sicheren Zugriff

    Setup¶

    1. Google Cloud Console¶

    1. Projekt erstellen:
    2. Gehen Sie zu: https://console.cloud.google.com
    3. Melden Sie sich mit Ihrem Vereins-Google-Account an
    4. IAM und Verwaltung → Projekt erstellen

    5. Geben Sie dem Projekt einen Namen

    6. Google Calendar API aktivieren:

    7. APIs und Dienste → Bibliothek
    8. Suchen Sie nach "Google Calendar API"

    9. Klicken Sie auf "Aktivieren"

    10. OAuth-Zustimmungsbildschirm:

    11. APIs und Dienste → OAuth‑Zustimmungsbildschirm
    12. Zielgruppe: Testnutzer
    13. Fügen Sie Ihren Google-Account als Testnutzer hinzu

    2. OAuth 2.0 Credentials¶

    1. Client ID erstellen:
    2. APIs und Dienste → Anmeldedaten
    3. Anmeldedaten erstellen → OAuth‑Client‑ID

    4. Anwendungstyp: "Webanwendung"

    5. Autorisierte Weiterleitungs-URIs:

    6. Lokal: http://localhost:3000/calendarToken
    7. Production: https://your-domain.com/calendarToken

    ⚠️ Wichtig: Die URI muss exakt übereinstimmen!

    1. Credentials speichern:
    2. Kopieren Sie die Client-ID
    3. Kopieren Sie den Clientschlüssel
    4. Speichern Sie diese sicher

    3. Environment-Variablen¶

    Setzen Sie in Ihrer .env Datei:

    GOOGLE_CALENDAR_CLIENT_ID=your_client_id.apps.googleusercontent.com
GOOGLE_CALENDAR_CLIENT_SECRET=your_client_secret
GOOGLE_CALENDAR_REDIRECT_URI=http://localhost:3000/calendarToken

    Für Production: 

    GOOGLE_CALENDAR_REDIRECT_URI=https://your-domain.com/calendarToken

    Kalender verknüpfen¶

    1. Bot-Befehl ausführen¶

    Im Discord-Server:

    /linkcalendar

    2. OAuth-Flow¶

    1. Der Bot sendet Ihnen einen Link
    2. Klicken Sie auf den Link
    3. Sie werden zu Google weitergeleitet
    4. Autorisieren Sie den Zugriff
    5. Sie werden zurückgeleitet
    6. Der Bot bestätigt die Verknüpfung

    3. Synchronisation starten¶

    /synccalendar

    Dies synchronisiert alle Events aus dem Google Calendar mit Discord.

    API-Endpunkte¶

    Kalender-Info¶

    GET /api/calendar/info/:guildId - Ruft Kalender-Informationen ab

    PUT /api/calendar/info/:guildId - Speichert Kalender-Informationen

    OAuth¶

    GET /api/calendar/link-url - Generiert OAuth-Link

    GET /api/calendar/callback - Verarbeitet OAuth-Callback

    Synchronisation¶

    POST /api/calendar/sync - Synchronisiert Google Calendar → Datenbank

    POST /api/calendar/from-discord/create - Erstellt Event von Discord → Google Calendar

    POST /api/calendar/from-discord/update - Aktualisiert Event von Discord → Google Calendar

    GET /api/calendar/provider-events - Ruft Events vom Provider (Google Calendar) ab

    Funktionsweise¶

    Google Calendar → Discord¶

    1. Synchronisation: 

      /synccalendar

    2. Ablauf:

    3. Bot ruft Events aus Google Calendar ab
    4. Events werden in Datenbank gespeichert

    5. Events werden im Discord #events Channel angezeigt

    6. Automatische Updates:

    7. Events werden regelmäßig aktualisiert
    8. Änderungen werden im Discord reflektiert

    Discord → Google Calendar¶

    1. Event erstellen:
    2. Vorstand erstellt Event im Dashboard
    3. Event wird in Datenbank gespeichert

    4. Event wird an Google Calendar gesendet

    5. Event aktualisieren:

    6. Änderungen im Dashboard
    7. Automatische Synchronisation mit Google Calendar

    Event-Verwaltung¶

    Discord-Commands¶

    Befehl Beschreibung
    /events Zeigt geplante Events
    /linkcalendar Verknüpft Google Calendar
    /synccalendar Synchronisiert Events

    • Event-Erstellung

    Event-Erinnerungen¶

    Der Bot sendet automatisch Erinnerungen für anstehende Events:

    • 24 Stunden vorher
    • 1 Stunde vorher

    Erinnerungen werden im Discord #events Channel gepostet.

    Troubleshooting¶

    "OAuth callback failed"¶

    • Prüfen Sie die GOOGLE_CALENDAR_REDIRECT_URI
    • Sie muss exakt mit der in Google Cloud Console übereinstimmen
    • Prüfen Sie, ob der Port korrekt ist (3000 für API)

    "Calendar not linked"¶

    • Führen Sie /linkcalendar erneut aus
    • Prüfen Sie die OAuth-Credentials
    • Prüfen Sie die Logs: docker-compose logs discord-bot

    "Sync failed"¶

    • Prüfen Sie die Google Calendar API-Berechtigungen
    • Prüfen Sie, ob der Kalender zugänglich ist
    • Prüfen Sie die Logs: docker-compose logs clanscore-api

    "Events not showing in Discord"¶

    • Führen Sie /synccalendar aus
    • Prüfen Sie, ob der #events Channel existiert
    • Prüfen Sie die Bot-Berechtigungen im Channel

    Best Practices¶

    Sicherheit¶

    1. OAuth-Credentials:
    2. Niemals in Git committen
    3. Verwenden Sie GitHub Secrets für Production

    4. Regelmäßig rotieren

    5. Berechtigungen:

    6. Minimal notwendige Berechtigungen
    7. Nur auf Vereins-Kalender zugreifen

    Wartung¶

    1. Regelmäßige Synchronisation:
    2. Täglich automatische Sync

    3. Manuelle Sync bei Bedarf

    4. Event-Bereinigung:

    5. Alte Events automatisch archivieren
    6. Regelmäßig Kalender aufräumen
